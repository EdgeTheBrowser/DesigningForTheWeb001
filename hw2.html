Block vs Inline

A small practice page showing how common HTML elements behave by default.

HTML practice

This is a normal div: it is a block element.
It starts on a new line and takes the full available width unless limited.
This div has id="highlight-card".
An ID must be unique on the page.
Inline elements stay in the text flow:

Normal text with a highlighted word.
This is very important information!
We can also do fancy dotted underline text.
Quick summary: default display

Block: new line and full width
div, p, h1-h6, section, article, header, footer, ul, ol, li

Inline: flows with text and uses only the needed width
span, a, strong, em, code, small, img
