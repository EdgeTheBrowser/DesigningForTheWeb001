How the 2-level sprite nav works

  • Level 1 – horizontal flex bar with sprite icons (Home, About, Services, Portfolio, Contact).
  • Level 2 – absolute-positioned dropdown lists that appear on :hover / :focus-within.
  • All navigation icons come from one embedded SVG sprite via CSS background-position, so no separate sprite file is needed.
  • No JavaScript required – pure CSS.
  • Every menu item is a real <a> link with an href.

Responsive layout: Flexbox and Grid

This page adapts its layout to the available screen width, so the navigation and content remain comfortable to use on phones, tablets, and desktop screens.

How this page responds

  • The main navigation uses Flexbox on wider screens to arrange its five links in a horizontal row.
  • Below 700px, the navigation switches to a three-column CSS Grid. The icons shrink, and dropdowns are repositioned to stay within the screen.
  • The photo gallery uses a flexible Grid that fits two cards side by side when there is room and stacks them into one column on narrow screens.
  • Below 480px, the page reduces some spacing and lets the image height follow its width, keeping each photo in a consistent shape.

Flexbox vs. Grid

  • Flexbox is one-dimensional: it arranges items in a row or a column. Use it for a navigation bar, toolbar, or a line of buttons when you mainly care about spacing and alignment in that one direction.
  • Grid is two-dimensional: it arranges items in rows and columns together. Use it for galleries and page layouts when you want to control how content fits into both dimensions.
  • Rule of thumb: choose Flexbox when arranging items along one axis; choose Grid when arranging a group across rows and columns. A page can use both, as this one does.
